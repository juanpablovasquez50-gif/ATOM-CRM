# Atom CRM
CRM interno para Atom Labs. MVP inicial: dashboard, prospectos, pipeline, tareas, clientes y almacenamiento local.

## Desarrollo
```bash
npm install
npm run dev
```

## Nota de seguridad
Este MVP usa almacenamiento local del navegador y una pantalla de acceso demostrativa. No usar para información sensible ni como acceso multiusuario real. El repositorio es público por decisión inicial; no incluir secretos ni datos reales. La arquitectura se mantendrá lista para conectar un backend en una fase posterior.
